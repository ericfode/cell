# Ecological challenge laboratory

Cell-zero is evolved by generated environmental pressure rather than architectural feature requests. The organism receives public examples, public checks, budgets, capability handles, and sealed roots. Hidden generators and seeds remain laboratory-only.

## Promotion order

The laboratory applies hard gates lexicographically:

1. no invalid promotion
2. exact replay and intact lineage
3. every inherited regression passes
4. the current challenge threshold passes
5. the resource budget passes
6. only then compare cost and latency

`organism/current` records the descendant selected by Cell-zero. `lab/champion` records the latest descendant that passed the external hidden gates. The refs are separate and durable.

A stage requires three passing lineages with distinct hidden seed roots. Passed challenges become inherited regressions. The laboratory never exposes or delegates its hidden generators.

## Current stage: C0, Event Eater

The generated distribution contains ordinary inputs, model-result-shaped events, timeouts, duplicate events, malformed events, replay at generated event boundaries, interrupted executions, durable pending effects, and restart-compatible partial logs.

Hard counters must all remain zero:

- replay root mismatches
- unrecorded effects during replay
- lost committed events
- silently skipped malformed events
- laboratory execution errors

Three independent 10,000-history lineages are required before C1 can begin. The first pressure finding was that malformed input was appended before validation. `submit-event` now rejects malformed input before mutating the event log.
